# Aquarela Maquillaje — Dashboard Editorial

Dashboard editorial interactivo para planificación de contenido en Instagram.

## Funcionalidades

- 📋 17 piezas editoriales Semana 1 (carruseles, posts, stories)
- 🎨 Cambiador de paleta de colores en tiempo real
- 🤖 Generador IA de contenido Semana 2 con Groq
- 📱 Diseño responsivo

## Despliegue

Este sitio está publicado en GitHub Pages.  
URL: `https://<tu-usuario>.github.io/aquarela-app/`

## Tecnologías

- HTML / CSS / JavaScript puro (sin dependencias)
- Google Fonts (Cormorant Garamond + Jost)
- Groq API (LLaMA 3.3 70B) para generación de contenido
